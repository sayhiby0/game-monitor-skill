# game-monitor-skill

Skill: 游戏舆情监控

输入一个游戏名称，从官网、官方社区、TapTap、NGA、Reddit、机核、游民星空等多渠道采集该游戏的最新动态，分析舆论走向（正面与负面）、运营/营销事件、创新玩法与口碑亮点，输出结构化 Markdown 舆情报告。

## 功能特性

- **多渠道数据采集**：官网、TapTap、NGA、百度贴吧、Reddit、机核、游民星空、3DM、GameLook、IGN、GameSpot 等 20+ 渠道
- **四维舆情分析**：舆情概览、事件与活动动态、创新与玩法亮点、口碑亮点
- **预制热门游戏渠道**：米哈游系（原神、星穹铁道、绝区零）、腾讯系（王者荣耀、和平精英、英雄联盟）、明日方舟、鸣潮
- **双维度渠道架构**：社区维度（通用游戏论坛/媒体）+ 游戏维度（每款游戏的专属信息源映射）
- **并行子 agent 采集**：4 个子 agent 并行工作，分别负责官方渠道、社区舆情、媒体报道、活动营销
- **多游戏对比**：支持同时对比多款游戏的舆情
- **定时监控**：可配合 QoderWork 定时任务实现周期性舆情报告
- **与 /game-daily 互补**：game-daily 做行业全局资讯，game-monitor 做单款游戏深度舆情

## 触发方式

- 斜杠命令：`/game-monitor <游戏名>`
- 自然语言：「查一下原神的舆情」「星穹铁道最近口碑怎么样」「Palworld reputation」

## 安装

将本仓库的 `SKILL.md` 文件放置到 QoderWork skills 目录：

```
~/.qoderwork/skills/game-monitor/SKILL.md
```

或通过 QoderWork 的 Skill 管理功能直接安装。

## 输出示例

报告以 `.md` 文件形式输出，包含以下章节：

1. 舆情概览（正面声音 / 负面声音 / 争议焦点）
2. 活动与事件动态（运营活动 / 营销事件 / 社区事件）
3. 创新与玩法亮点
4. 口碑亮点
5. 数据来源明细
6. Sources（引用链接）
